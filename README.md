# BOOMBIT — Mixed Reality Confusion

혼동현실(Mixed Reality Confusion) 퀴즈/퍼즐 게임.

## 컨셉
현실인지 가상인지 분간이 안 가는 세계관에서 가치판단 의문을 해결해 나가는 인터랙티브 내러티브 게임. 플레이어의 선택에 따라 심리/기질 검사 결과가 도출된다.

## 기술 스택
- HTML5 + CSS3 + Vanilla JavaScript
- 외부 라이브러리 없음 (Google Fonts만 CDN)
- `data/scenarios.json`에서 시나리오/퀴즈/결과 데이터 로드

## 구조
```
Boombit/
├── index.html          # 게임 진입점
├── style.css           # 글리치/리미널 비주얼 테마
├── game.js             # 게임 엔진 (상태 관리, 화면 전환, 선택 추적)
├── data/
│   └── scenarios.json  # 시나리오, 퀴즈, 심리 결과 데이터
└── README.md
```

## 게임 플로우
1. **인트로** — 글리치 타이틀 + 세계관 소개
2. **내레이션** — 사건 제시 (텍스트 애니메이션)
3. **선택지** — 4가지 선택 → 성향 점수 누적
4. **퀴즈/퍼즐** — 텍스트 입력 퀴즈 (정답/오답 분기)
5. **결과** — 4가지 성향 중 지배적 기질 산출 + 시각화

## 성향 유형
| 유형 | 아이콘 | 설명 |
|------|--------|------|
| 이성적 분석가 | 🧠 | 논리와 증거 기반 판단 |
| 감성적 공감자 | 💗 | 감정과 공감 기반 판단 |
| 혼돈의 탐험가 | 🌀 | 규칙 밖의 창의적 접근 |
| 현실적 해결사 | ⚙️ | 효율과 결과 중심 |

## 실행
브라우저에서 `index.html` 열기. 로컬 서버 권장 (JSON fetch 때문에):
```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
